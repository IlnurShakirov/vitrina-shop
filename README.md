# Высокотехнологичный маркетплейс «Смартфон Shop» с гибридным ИИ-консультантом

Современная e-commerce платформа на базе микросервисной архитектуры, оснащённая интеллектуальным ИИ-подборщиком товаров (RAG-архитектура), автоматизированной системой документооборота и многоуровневым кэшированием.

## 🛠 Технологический стек
- **Backend:** Python 3.11+ / Django 5.x (SPA-архитектура через AJAX/Fetch API)
- **Основная СУБД:** PostgreSQL (реляционная база данных для транзакций и каталога)
- **NoSQL / Кэш:** Redis (кэширование сессий, корзин покупателей и QuerySet)
- **AI-ядро:** Ollama / Meta Llama 3.2 (локальный искусственный интеллект в закрытом контуре)
- **Окружение:** Docker / Docker Compose (полная контейнеризация всех микросервисов)
- **Документооборот:** ReportLab (генерация бинарных PDF-инвойсов на лету)

## 🚀 Ключевой функционал систем
- **Гибридный ИИ-Поиск (RAG):** Отказоустойчивый бэкенд на Python анализирует падежи по усечённым корням слов, сопоставляет запросы покупателей со спецификациями PostgreSQL и намертво отсекает неподходящие бренды, автоматически перестраивая витрину и ползунки цен. Локальная нейросеть отвечает за генерацию развёрнутого человеческого вердикта.
- **Интеллектуальный бэк-офис:** Администратор может в один клик модерировать отзывы, одобрять их в панели управления, а также управлять наличием товаров на складе (флаг `is_available`).
- **Автоматизация PDF-чеков:** При подтверждении оплаты в Личном кабинете генерируется официальный международный инвойс (PDF) со сквозным выводом фамилии и инициалов ответственного администратора на основе динамической транслитерации.
- **SPA-Интерфейс:** Фильтрация, поиск, AJAX-добавление в Избранное и корзину без перезагрузки страниц сайта.

## 📦 Быстрое развертывание проекта через Docker

Вся экосистема маркетплейса полностью контейнеризирована. Для запуска вам не нужно устанавливать Python, PostgreSQL или Redis на хост-машину — достаточно иметь установленный Docker Desktop.

1. **Клонируйте репозиторий проекта:**
   ```bash
   git clone https://github.com
   cd vitrina-shop
   ```

2. **Запустите сборку и контейнеры микросервисов:**
   Выполните команду в терминале (команда автоматически соберёт образы, настроит внутренние сети, применит миграции базы данных и соберёт статику):
   ```bash
   docker compose up -d --build
   ```

3. **Загрузите и активируйте ИИ-модель внутри контейнера:**
   Отправьте команду запуска нейросети во внутренний изолированный контейнер Ollama:
   ```bash
   docker exec -it vitrina_ai_ollama ollama run llama3.2
   ```
   *Дождитесь статуса `success >>>`, после чего локальный искусственный интеллект будет полностью готов к работе.*

4. **Создайте учётную запись главного администратора:**
   ```bash
   docker compose exec web python manage.py createsuperuser
   ```
   *После создания зайдите в панель управления `http://127.0.0`, откройте профиль своего администратора и заполните поля "Имя" и "Фамилия" для автоматической транслитерации подписи в PDF-чеках.*

5. **Тестирование платформы:**
   Откройте Яндекс.Браузер и перейдите по адресу:
   ```text
   http://127.0.0
   ```

## 🔐 Безопасность и отказоустойчивость системы
- Локальный запуск ИИ-модели Llama 3.2 полностью исключает утечку коммерческих данных из PostgreSQL во внешние облачные сервисы и защищает систему от блокировок брандмауэра.
- Бэкэнд Django защищён от сбоев ИИ: при временном отсутствии связи с контейнером Ollama или задержке генерации, Python автоматически переключается в безопасный режим Fallback-генерации текста, предотвращая падение интерфейса.
- Реализован комплексный Кэш-бастинг (`_nocache`) на фронтенде, исключающий застревание старых AJAX-ответов в кэш-памяти браузеров.
