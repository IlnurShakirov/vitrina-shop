Смартфон Shop 📱

Разработка e-commerce маркетплейса электроники

Веб-приложение для онлайн-продажи смартфонов с интеграцией гибридного e-commerce ИИ-подборщика на базе RAG-архитектуры (Llama 3.2 / Ollama) и автоматической генерацией коммерческих ReportLab PDF-чеков.

Автор проекта: Шакиров Ильнур Динарович

Группа: PythonPro511

Уфа, 2026 год

🎯 ПРЕДМЕТНАЯ ОБЛАСТЬ

Онлайн-ритейл и умные e-commerce продажи

Современный рынок электронной коммерции требует перехода от статичных, неудобных фильтров каталога к интерактивному интеллектуальному взаимодействию с покупателем.

🧠 Умный подбор

Покупатель описывает свои цели человеческим языком вместо долгого поиска по галочкам технических характеристик.

🗣️ Простым языком: Вместо ручного выбора процессоров, пишем: «нужен недорогой телефон для школьника», и сайт сам понимает задачу.

📄 Автоматизация

Мгновенное формирование легитимных торговых инвойсов в формате PDF на стороне сервера при совершении платежной транзакции.

🧾 Простым языком: Сразу после оплаты сайт автоматически генерирует красивый чек, который можно скачать и распечатать.

⚡ SPA-архитектура

Полное отсутствие перезагрузок страниц сайта при навигации по разделам, асинхронном добавлении товаров в корзину и управлении профилем.

🚀 Простым языком: Всё работает молниеносно на одной странице, как в мобильном приложении — без белых экранов и загрузок.

04 / 09

🏗 ИННОВАЦИОННЫЕ ФУНКЦИИ И ОПТИМИЗАЦИЯ

Глубокая инженерная проработка ИИ-ассистента и бэкенд-логики

✨ Сложные ТТХ простым языком

Интегрирована функция семантического перевода сложных аппаратных спецификаций. ИИ преобразует непонятные пользователю аббревиатуры процессоров и матриц в понятные жизненные сценарии.

🗣️ Пример работы функции: Вместо сухой строки «MediaTek Helio G99, IPS 120Hz» ИИ выводит: «Отлично потянет любые современные игры и обеспечит очень плавное пролистывание меню».
🔄 Паттерн RAG (Retrieval-Augmented Generation)

Динамическое обогащение промпта нейросети Ollama актуальными складскими остатками из PostgreSQL непосредственно перед отправкой запроса.

🧠 Простым языком: ИИ не фантазирует — перед ответом бэкенд передает нейросети точный список и цены моделей, которые прямо сейчас есть у нас в наличии на складе.

◄─────────────────── Миграция данных при оплате заказа
🧾 При успешной оплате скрипт бэкенда переносит выбранные `product_id` из корзины в чек таблицы Order и очищает сессию.
🗄️ Архитектурное резюме СУБД: Инфологическая структура базы данных спроектирована в соответствии с требованиями третьей нормальной формы (3NF). Наличие строгих ограничений целостности через внешние ключи (Foreign Key) полностью ликвидирует избычность данных и исключает аномалии обновления. Это гарантирует абсолютную транзакционную безопасность при асинхронной работе корзины, формировании гибридного ИИ-контекста и генерации серверных ReportLab PDF-инвойсов.

🚀 МАСШТАБИРУЕМОСТЬ И ПЕРСПЕКТИВЫ РАЗВИТИЯ

Коммерческое масштабирование и ИИ-модернизация платформы

Разработанная архитектура Смартфон Shop имеет высокий потенциал для дальнейшего enterprise-развития и монетизации по трем направлениям:

🌐 Модель Multi-Vendor

Модернизация базы данных PostgreSQL и личного кабинета для регистрации сторонних продавцов (ритейлеров). Трансформация локального магазина в полноценный открытый маркетплейс электроники масштаба Ozon или Wildberries.

🎙️ Voice-to-Text подбор

Интеграция браузерного Web Speech API для распознавания речи. Покупатели (включая пожилых людей) смогут осуществлять гибридный ИИ-подбор смартфонов при помощи простых голосовых команд без ввода текста.

📊 ИИ-аналитика для бизнеса

Интеграция предиктивных алгоритмов машинного обучения в Django-админку. Система сможет автоматически анализировать историю заказов и прогнозировать спрос на дефицитные модели смартфонов.

📈 Простым языком: В будущем сайт сможет принимать тысячи продавцов, понимать голосовые команды покупателей на лету и автоматически подсказывать владельцу магазина, какие смартфоны нужно срочно заказать на склад, основываясь на анализе прошлых продаж.
